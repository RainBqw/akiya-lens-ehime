# Akiya Lens Ehime

Akiya Lens Ehimeは、愛媛県の空き家問題に着目した、空き家リスク診断・巡回支援Webアプリです。

## 解決したい課題

地域で増加する空き家は、管理が不十分になると、倒壊、景観悪化、雑草や樹木の繁茂、道路への影響など、周辺住民の生活環境に影響を与える可能性があります。

しかし、限られた人員で全ての空き家を同じ頻度で確認することは難しく、どの空き家を優先して巡回・対応すべきか判断しにくいという課題があります。

## 作品概要

Akiya Lens Ehimeは、空き家ごとに点検履歴を記録し、建物劣化や周辺への影響をスコア化することで、対応優先度を可視化するアプリです。

## 主な機能


- 空き家一覧表示
- 高リスク空き家トップ3表示
- 空き家詳細表示
- 点検タイムライン表示
- 点検フォーム
- リスクスコア自動計算
- 写真プレビュー
- 写真付き点検履歴
- コンポーネント分割


## デモ操作シナリオ

1. 高リスク空き家トップ3を確認する
2. 緊急確認の物件を選択する
3. 過去の点検履歴を確認する
4. 点検写真を選択する
5. 劣化状態に応じてチェックを入れる
6. リスクスコアの自動計算結果を確認する
7. コメントを入力して点検を登録する
8. タイムラインとランキングが更新されることを確認する

## リスクスコアの考え方

点検項目に応じて点数を加算します。

- 屋根破損あり: +25
- 外壁破損あり: +15
- 雑草が多い: +15
- 道路にはみ出し: +10
- ごみあり: +10
- 前回より悪化: +10
- 60日以上未点検: +5

スコアに応じて、以下のように分類します。

- 0〜29: 低リスク
- 30〜59: 要観察
- 60〜79: 要対応
- 80〜100: 緊急確認
